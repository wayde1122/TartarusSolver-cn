# Application icon

`gugugaga.png` is a circular portrait crop of the 咕咕嘎嘎 penguin character.
`gugugaga.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 pixel versions
for the Windows executable and WPF window icon.
